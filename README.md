
우아한테크코스 웹 백엔드 최종 코딩테스트 대비를 위한 연습용 프로젝트: 점심 메뉴 추천

---

## 🎯 프로젝트 개요

우아한테크코스 최종 코딩테스트를 대비하기 위한 연습용 프로젝트입니다.   
점심 메뉴 추천 프로그램을 구현합니다.

---

## 📝 구현 기능 목록

### 1. 기본 정보 설정
- [x] **시작 문구 출력**
- [x] **코치 이름 입력**
  - 입력 안내 문구 출력
  - 이름 목록 입력 (`,` 로 구분해서 입력)
  - **이름 목록 예외 처리**
    - 빈값 / 공백
    - 최소 2명, 최대 5명
    - 이름 최소 2글자, 최대 4글자
  - 예외 발생 시 에러 문구 출력, 재입력
- [x] **코치별 못먹는 메뉴 입력**
  - 입력 안내 문구 출력
  - 메뉴 목록 입력 (`,` 로 구분해서 입력)
  - **메뉴 목록 예외 처리**
    - 최소 0개, 최대 2개
  - 예외 발생 시 에러 문구 출력, 재입력

### 2. 메뉴 추천 (월~금)
- [x] **추천 카테고리 선정**
  - 한 주에 같은 카테고리는 최대 2회까지
  - `Randoms.pickNumberInRange()`의 결과가 1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식을 추천
- [x] **코치별 메뉴 추천**
  - 각 코치에게 한 주에 중복되지 않는 메뉴 추천
  - 카테고리에 포함되는 메뉴 목록을 `List<String>` 형태로 준비
  - `Randoms.shuffle()`을 통해 임의의 순서로 섞은 후, 첫 번째 값을 사용

### 3. 결과 출력
- [x] **메뉴 추천 결과 출력**
- [ ] **종료 문구 출력**
